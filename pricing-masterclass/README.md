# Pricing Masterclass — Lecture 1: Quantitative Pricing (built site)

Static build. Serve from the **repo root** so `../config.js` (the shared Ably key) is found, then open `/pricing-masterclass/`:

    python -m http.server 8000     # from the repo root
    http://localhost:8000/pricing-masterclass/

On GitHub Pages: https://risbhard.github.io/chapter11_12/pricing-masterclass/

- Projector: Previous / Next buttons or ← →, **F** = full screen. "Presenter view" opens the notes window.
- Students scan the QR code on the challenge page (needs the Pages URL, not localhost).
- The instructor answer key is NOT in this repo. Load your local `brolan-answer-key.json` once in Presenter view.
